Rotas e componentes — ClimaMonitor em Next.js

Qual componente aparece em qual rota, e o que cada rota lê e chama.

O que cada rota lê e chama

Cada rota liga a um ou mais recursos. Passe o mouse ou o foco (Tab) numa rota para ver só as ligações dela.

Rotas

/ — Comparar

Server + formulário Client

Componentes
FormularioComparar, OpcoesLocalidade ×2
Ao montar
GET /dados/localidades.json → dropdown. Enquanto carrega: selects e botão desabilitados, mensagem em aria-live
Ao comparar
GET /api/clima/{slug} ×2 → compararLocalidades → sessionStorage → /resultado

/resultado — Resultado

Client

Componentes
ResultadoComparacao, FiltroIndicador, BotaoFavoritar, BotaoCompartilhar
Rede
Nenhuma. Lê o sessionStorage; sem dado salvo mostra RESULTADO_EXEMPLO (em código)
URL
?indicador=geral|temperatura|chuva|umidade|vento

/mapa — Mapa

Client

Componentes
MapaLocalidades, CartaoMapa ×2, OpcoesLocalidade ×2
Rede
GET /dados/localidades.json: lista e campo mapa (SVG + alt) de cada cidade
Entrada
sessionStorage pré-seleciona A e B

/favoritos — Favoritos

Client

Componentes
ListaFavoritos + Link “Nova comparação”
Entrada
localStorage (em useEffect)
Abrir favorito
GET /dados/localidades.json + GET /api/clima/{slug} ×2 → sessionStorage → /resultado

/api/clima/[slug]

Backend Route Handler

Entrada
Slug (ex.: sao-paulo-sp)
Saída
{temperatura, umidade, chuva, vento} em °C, %, mm, km/h
Erros
404 slug desconhecido · 502 OpenWeather · 500 sem chave
