Arquivos e o que cada um carrega

Servidor, backend, cliente e lib
Arquivo Lado Papel Carrega / usa
app/layout.js Server Casca HTML e template de título globals.css
app/page.js, mapa/, favoritos/ Server Montam a tela e entregam o componente Client Cabecalho, Navegacao, Rodape + FormularioComparar, MapaLocalidades, ListaFavoritos
app/resultado/page.js Server Só delega: o cabeçalho depende do resultado salvo ResultadoComparacao, Rodape
app/api/clima/[slug]/route.js Backend Proxy da OpenWeather public/dados/localidades.json, process.env.OPENWEATHER_API_KEY
Cabecalho, Navegacao, Rodape Server Estrutura repetida nas telas next/link, CSS modules
OpcoesLocalidade Server → roda no cliente <option> dos selects; recebe localidades por prop — (importado por Client Components)
FormularioComparar Client Formulário A × B; compara e navega listarLocalidades, montarLeitura, compararLocalidades, salvarResultadoComparacao, router.push
ResultadoComparacao Client Tela Resultado inteira obterResultadoComparacao, funções de comparar-clima, Cabecalho, Navegacao, FiltroIndicador, BotaoFavoritar, BotaoCompartilhar, window.location.search
FiltroIndicador Client Radios "Comparar por" — (devolve a escolha por aoMudar)
BotaoFavoritar Client Alterna favorito ehFavorito, favoritarComparacao, removerFavorito (localStorage)
BotaoCompartilhar Client Compartilhar resultado navigator.share, senão navigator.clipboard
ListaFavoritos Client Lista e reabre favoritos obterFavoritos, removerFavorito, montarLeitura, compararLocalidades, salvarResultadoComparacao
MapaLocalidades Client Seleção A/B e SVG ilustrativo listarLocalidades, obterResultadoComparacao, OpcoesLocalidade
lib/cliente-api.js lib Cliente único do front: listarLocalidades, obterLocalidade, buscarClima fetch, AbortController, cache da lista
lib/montar-leitura.js lib Localidade → clima (backend) → riscos → índice → orientação cliente-api, indice-climatico, orientacao
comparar-clima, indice-climatico, orientacao lib Regra de negócio pura —
armazenamento-comparacao, armazenamento-favoritos lib Persistência no navegador sessionStorage, localStorage

Notas

  • Um módulo importado por um Client Component vira cliente, mesmo sem diretiva: OpcoesLocalidade em / e /mapa; Cabecalho e Navegacao em /resultado.
  • No servidor não existem sessionStorage nem localStorage: o primeiro render sai vazio e os dados entram no useEffect.
